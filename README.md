# CatNay • Policy Summary

เว็บภาษาไทยสำหรับสรุปกรมธรรม์หลายบริษัทและเทียบเป้าหมาย 6 ประเภท เปิด index.html ได้โดยไม่ต้องติดตั้งแพ็กเกจ

## ใช้งาน
1. ข้อมูลและเป้าหมาย: กรอกข้อมูลลูกค้าและสมมติฐาน กดคำนวณ หรือแก้เป้าหมายเอง
2. กรมธรรม์ของฉัน: เพิ่มบริษัท เลขกรม แบบประกัน ผู้เอาประกัน ผู้ถือ ผู้รับผลประโยชน์ เบี้ยต่องวด วันครบกำหนด ช่วงคุ้มครอง และผลประโยชน์
3. ภาพรวม: ดูวงกลมเปรียบเทียบเป้าหมาย ตารางรายกรม และวงเงินรักษารายแผน
4. พิมพ์ / PDF: ใช้เมนูบันทึกเป็น PDF ของเบราว์เซอร์

ข้อมูลเก็บเฉพาะ Local Storage ของเบราว์เซอร์ ไม่มีระบบบัญชีหรือ Cloud sync และไม่มีการส่งข้อมูลลูกค้าเข้า repository ลูกค้ากรอกเองแล้วส่งไฟล์ JSON ให้ที่ปรึกษาได้ ควรสำรอง JSON ก่อนเปลี่ยนอุปกรณ์หรือเคลียร์เบราว์เซอร์

## วิธีคำนวณ
- ชีวิต = max(0, ค่าใช้จ่ายต่อปี × ปีดูแล + หนี้ + เป้าหมายผู้พึ่งพิง − สินทรัพย์ที่จัดสรร)
- CI ต้น–กลาง / รุนแรง = รายได้ต่อปี × ปีพักฟื้นแต่ละระยะ
- อุบัติเหตุ = เป้าหมายชีวิต × ตัวคูณ (แสดงเฉพาะทุนอุบัติเหตุเพิ่มเติม)
- ค่าห้อง = งบที่ผู้ใช้กรอกเอง ไม่มีฐานราคาห้องโรงพยาบาลอัตโนมัติ
- ชดเชย = รายได้ต่อปี ÷ 365 × สัดส่วนชดเชย
- เป้าหมาย 0 แสดงว่ายังไม่ได้ตั้งเป้าหมาย ไม่แสดงเป็น 100%
- รวมเฉพาะสถานะมีผลบังคับ / ชำระครบ ที่อยู่ในช่วงวันคุ้มครอง
- เบี้ยประจำรายปีเทียบจากงวดชำระ เบี้ยครั้งเดียวไม่รวมเบี้ยประจำ
- ไม่รวมวงเงินค่ารักษาต่างฐานเป็นยอดเบิกได้จริง แสดงฐานวงเงิน deductible และหมายเหตุรายแผน
- ผลประโยชน์ต่างหมวดอาจจ่ายทดแทนกัน ขึ้นกับเงื่อนไขจริง สูตรเป็นสมมติฐานสำหรับวางแผน ปรับได้ ไม่ใช่สูตรทางการของ AIA
